# 发给 Gemini 的操作清单（照这个顺序复制）

**目的**：Gemini 所在环境无法访问 GitHub，所以必须由你**手动粘贴**。
本清单告诉你**按什么顺序打开哪个文件、复制什么**。

**⚠️ 顺序很重要**：**第 0 步（任务说明）必须先发**——它规定了审阅要求；
否则 Gemini 不知道要查什么、要遵守哪三条注意事项，会报出一堆假问题。

```
（全文）
===== END OF FILE: PROJECT_STATE.md =====
```

## 发送小技巧

1. **一批发一条消息**，不要一条消息里塞多批（容易截断且难定位）
2. **等它回复"收到"再发下一批**，不要连发 6 条
3. 若某批粘贴后**明显变短或结尾缺失**，**别继续发**——先告诉我第几批、缺在哪里
4. 全部发完后，说一句：**「材料发完了，请开始按 A/B/C/D 四节输出复核报告」**
