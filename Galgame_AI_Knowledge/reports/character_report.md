# 人物识别报告

## 一、识别方法

剧本的说话人由独立一行的 `【…】` 标签给出，因此**角色识别不是靠猜测**：

```
【桜小路ルナ】
「ん、朝日か。おはよう」[n]
```

解析器据此把台词归属到具体角色，并保留：

- 原始标签（`speaker_label`，如 `スタンレー＠フランス語の声`）
- 角色名（`speaker`）与注记（`speaker_note`）
- 来源文件、行号、来源 pack、语音编号

标签中 `＠` 之后的注记表示「同一角色的不同语体/身份」（例如露娜对朝日说话时的特殊标注、
スタンレー说法语时的标注），已在数据层保留，不做合并丢失。

## 三、主角的身份标签拆分（重要发现）

剧本用标签精确区分了主角的两种人格，统计结果与语体完全对应：

| 标签 | 句数 | 第一人称分布 |
| --- | --- | --- |
| 小倉朝日 | 5999 | 私 933、僕 280 |
| 小倉朝日＠大蔵遊星 | 1996 | 僕 378、私 65 |
| 大蔵遊星 | 523 | 僕 73、ぼく 15、私 13 |
| 小倉朝日＠大蔵朝日 | 144 | 私 54 |
| 大蔵遊星＠幼少時代の遊星 | 2 | ぼく 3 |

结论：**第一人称随身份切换**（女装·女仆＝私；真实自我＝僕／ぼく），
这为角色扮演提供了可直接使用的语体规则，而不是主观推测。

## 四、10 条「无具名说话人」台词的性质

这 10 条并非漏识别，而是**旁白句中引用的对话**，例如：

```
「『他の客の目もあり、娘に会わせたくない母もいる』。どうかお引き取り願いたい」と告げられた。
```

（`scenario/アフター/l33_02b0.s:346`）

它们已被保留在 `cleaned/messages.jsonl`，`speaker` 为空，可由人工决定是否归入旁白。
