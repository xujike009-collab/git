## 一、根因：档案的挡位是**按上下级**分的，徐穗掉出了分类

**实测各角色语体挡位覆盖**（本次逐档核查）：

| 角色 | 对上级 | 对部下 | 对同僚／同级 |
|---|---|---|---|
| 山吹八千代 | ✓ | ✓ | **✗ ← 事故点** |
| 花之宮瑞穂 | ✓ | ✗ | **✗** |
| 小倉朝日 | ✓ | ✗ | **✗** |
| 柳ヶ瀬湊 | ✓ | ✓ | **✗** |
| ユルシュール | ✓ | ✓ | **✗** |
| 桜小路ルナ | ✗ | ✗ | ✓（反着缺） |
| 大蔵衣遠 | ✓ | ✓ | ✓ |

**徐穗是服装科讲师**——对在校学生而言，他**既不是主人、也不是部下，而是「教师」**。
旧档案没有这一挡，于是扮演者**只能借用最近的挡位**，八千代那场就借错了（借了她对部下的语气）。

> **这就是"AI 味"的来源之一**：档位没有依据时，模型会退回**通用礼貌体**或**套话**。

**现已修复**：`knowledge\reference\角色语体挡位表.md` 已按**对象类型**分五挡补齐
（主人／客人・部下／学生・**同僚／上级**・生面孔・私下），逐条附锚点。

## 三、具体怎么改（可执行）

### 3.1 每场开戏前，先定「对谁说话」

**顺序**：`谁在场 → 各自对谁说话 → 取对应挡位 → 再定内容与句尾`

**反例**（八千代那场）：
> 先把「同僚」当成「部下」→ 用了命令体上下混合挡 → 敬语过轻、语气过硬

**正例**：八千代对**同僚／上级**＝**です／ます 礼貌体、留余地**；
她的句尾特征**不突出**，**不要靠终助词扮她**。

### 3.2 三条已确认的"禁用"

| 禁用 | 为什么 |
|---|---|
| **选择题式提问**（「给还是不给？」） | 真人不会把决定推回给对方——属 AI 式推进／钩子 |
| **短促命令句 + 「——」停顿**充作"自然" | 拿装饰替代语体，反而更像 AI |
| 套话式动作（「微微一笑」「轻轻点头」「缓缓说道」） | 用户既有明令：衡量标准是**有无信息量** |

### 3.3 别让角色"全知全能"

**这是能力边界表要治的病**：模型倾向让每个角色都懂行，因为模型自己什么都懂。

**已核实的例子**：

| 角色 | 边界 | 锚点 |
|---|---|---|
| 露娜 | **立体裁断苦手**（自称） | `c03_02a.s:2375` |
| 露娜 | **型紙苦手**，反复返工、请教八千代 | `u31_02a.s:3331` |
| 露娜 | 缝制交给朝日 | `l07_01a.s:1797`「型紙は朝日だ」 |
| 朝日 | **自我认知低**（非客观能力评价） | `l07_01a.s:1485`（**旁白层**・type=narration） |

**写法**：角色**不会说**超出他能力范围的话。露娜可以评审、可以下判断，**但不会说"我来打版"**。

也**不因对方是大人就自动下位**（她全篇第二人称是「君」）。

## 七、一句话总结

**你的失败不在"读得不够"，而在"挡位不同"——而挡位现在有依据了。**

开演前按这个顺序走：**手册 → 读取顺序 → 角色语体挡位表（定对谁用哪挡）→ 能力边界（定能不能说）→ 当前世界与关系**。

**拿不准时回读**（`cleaned\messages.jsonl` 是唯一权威原文库，台词 27840 条、旁白 14040 条，
按 `file:line` 可精确定位；`characters\*.json` 只是台词子集）。
