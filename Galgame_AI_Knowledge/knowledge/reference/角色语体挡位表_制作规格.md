## 一、为什么要这张表（**这是上次翻车的根因**）

**实际事故**：扮演者演山吹八千代时被用户判定「人机味重、不像她」。原因不是语体数据缺失，
而是**用错挡位**——把她的「对部下／学生」挡用在了**同僚（徐穗）**身上。

**根因是分类方式**：现有档案的挡位**按上下级分**——
「对主人／客人」与「对部下／学生」。而徐穗是**讲师、同僚**：
**既不是主人，也不是部下，于是直接掉出了分类。**

**核实现状**（本次已查，供参考）：

| 角色 | 对上级 | 对部下 | 对同僚／同级 |
|---|---|---|---|
| 山吹八千代 | ✓ | ✓ | **✗** |
| 花之宮瑞穂 | ✓ | ✗ | **✗** |
| 小倉朝日 | ✓ | ✗ | **✗** |
| 柳ヶ瀬湊 | ✓ | ✓ | **✗** |
| ユルシュール | ✓ | ✓ | **✗** |
| 桜小路ルナ | ✗ | ✗ | ✓（反着缺） |
| 大蔵衣遠 | ✓ | ✓ | ✓ |
| スタンレー | ✗ | ✗ | ✗ |

**结论**：多数角色**缺「对同僚」挡**，而这正是本 run 里与{{user}}最常发生的关系类型。

## 二、这张表的作用

它同时服务两件事：

1. **扮演者每场开演前的「在场对齐」**——按「谁在场 → 各自对谁说话 → 哪一挡」
   现场取用，不必凭印象（用户 2026-10-11 提出的缺口）
2. **语体把关**——出现「不像她」时可逐挡核对

> 注意：**归档者只提供这张底本**，不负责每场替扮演者生成对齐清单。

| 主人／客人 | … | … | … | … | — |

| **同僚／上司** | … | … | … | … | — |

| 私下／放松场合 | … | … | … | … | — |

**若某挡在语料里找不到依据 → 写「未找到依据」，不要推测。**

## 六、三条硬性规矩

**① 每条结论必须带 `file:line` 锚点**；无依据写「未找到依据」。

**② 只取「工艺／职务／社交」相关的原文。**
角色语料为成人向作品，**不得引用、转述或概括任何性相关内容**；
本 run 的角色设定为**未成年学生**，与语体挡位无关。

**③ 挡位划分按「对象类型」，不按「场合」。**
例：「对同僚」是对象类型；「在会议室」是场合，不单独建挡。

---

## 七、成品放哪

`knowledge\reference\角色语体挡位表.md`（归档者创建、维护）

**为什么不改进 `knowledge\characters\*.md`**：
- 本表是**横切结构**（一线一人，跨角色对照），与按角色纵向组织的档案不同构
- 避免多人同时改同一份人物档案（现有约定：一个档案一个写入者）

## 十、与「角色能力边界表」的关系

两表并列，各管一维：

| 表 | 管什么 | 回答的问题 |
|---|---|---|
| 角色能力边界表 | **能力** | 「她**能不能**说这句话、做这件事」 |
| **角色语体挡位表（本表）** | **语体** | 「她**该怎么**对这个人说话」 |

**两份都需要**：能力边界防止角色说出没资格说的话；挡位表防止角色用错语气。
