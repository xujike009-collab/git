## 四、归档流程（未变，供接手人参考）

```
扮演者停手/存档（只报告接续信息）
   ↓
用户关闭扮演者会话
   ↓
用户在普通 PowerShell 窗口导出（速查卡命令，含 --split-every 20）
   ↓
归档者：复验完整性 → 逐段全读 → 划界提取 → 更新四件套 → 报告（A/B/C/D 四节）
   ↓
归档完成后 → 通知用户 → 工具开发会话更新 §6/§7 指针 → 再开新扮演者
```

**关键约束**（详见《归档划界规则》与《双会话协作规范》）：
- **一批一导**：上一批归档完成前不导出其他会话
- **同一时间只开一个会话**（本项目无文件锁，并发写会静默覆盖）
- **原始导出只读**：不删、不移、不改写
- **同一档案只有一个写入者**：`knowledge/world/runs/` 四件套由归档者维护，扮演者只读
- **Git 提交由用户决定**
- **指针更新时机**：§6/§7 的接续点**只在归档完成后更新一次**，不随剧情推进逐场改
