# 角色扮演运行目录

> 本文件是全部「玩家角色线」的索引。每条角色线 = 一份独立档案，互不串线。
> 原作人物关系（canonical）在 `knowledge/relationships.md` 与 `knowledge/relationships_data.json`，**任何角色扮演都不得改动**；RP 产生的关系只写进各自 run 目录。
> 共享（跨线）资料：`knowledge/world/NPC时间表.md`（原作作息，与角色线无关）。

## 每条 run 目录内固定四件套

| 文件 | 内容 |
| --- | --- |
| `当前世界状态.md` | 时间／地点／在场人物／进行中事件 |
| `共同记忆.md` | 已发生事件与关系影响（NPC 引用「过去」只能出自这里） |
| `NPC对徐的认知.md` | 各 NPC 对**该玩家角色**的认识（告知／观察／共同经历／推测／未知） |
| `关系状态.json` | 多维关系状态＋变化事件记录（仅 AI 内部状态，不得报数字） |

## 如何操作

- **回到旧角色**：读对应 run 目录的 `当前世界状态.md` 与 `共同记忆.md`，即可接续。
- **开新角色**：复制 `_模板/` 四件套为新目录（编号递增，如 `002_xxx/`），把「徐」替换为新玩家名，从头开始第 1 轮。
- **每轮结束后**：更新当前 run 的四件套，再 `git` 提交。
